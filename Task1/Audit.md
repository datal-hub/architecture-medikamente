### Список проблемных зон
- Администратор имеет доступ к информации, которая составляет медицинскую тайну
- Врач может получить доступ к ПД и мед.данным пациента, который не наблюдается у него
- Потенциально любой сотрудник может получить несанкционированный доступ к почтовому серверу через который циркулируют чувствительные данные, если узнает логин/пароль врача
- Любой сотрудник лаборатории может изучить данные пациентов к которым он не имеет отношения

### Список данных для защиты
- Данные контракта пациента с медцентром (ПД)
  - шифрование (хранение и передача)

  - обфускация для аналитики

  - шифрование (хранение и передача)
  - маскирование для тестовых целей

  - шифрование (хранение и передача)
  - маскирование для тестовых целей

  - шифрование (хранение и передача)
  - маскирование для тестовых целей

## Механизм тегирования
Данным в нашей системе мы будем назначать следующие теги:
- PII - Personal Identifiable Information - ПД
- SPI - Sensitive Personal Information - специальные ПД
- PHI - Protected Health Information - данные составляющие медицинскую тайну
- CTI - Commercially Tracked Information - данные составляющие коммерческую тайну
- NPI - Non-Personally Information - не персональные данные

Так как на текущий момент основной канал обмена данными происходит через файлы и почту, то мы можем использовать Microsoft Azure Information Protection в качестве механизма для тегирования данных.
Данное решение позволит нам также обеспечить шифрование данных и контроль доступа через RBAC (с помощью Azure Active Directory).

### Cписок инструментов, способов и мер по обеспечению конфиденциальности

Помимо механизма тегирования нам стоит также обеспечить следующие меры:
- Мониторинг и аудит тегированных данных
  - тут можем воспользоваться инструментов в той же экосистеме - Microsoft Purview Audit
- Обучение и информированность персонала
  - необходимо провести обучение сотрудников работе с новой системов, рассказать про возможные угрозы
  - проводить регулярные учения
- Поддержание и обновление тегов
  - завести расписание и ответственных за аудит тегов
